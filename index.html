Useful details

Before you begin.

Will the app delete or rename desktop files?

No. It requests position changes through Windows Explorer. It does not rename or delete the desktop items it arranges.

Why must Auto arrange icons be disabled?

Windows Explorer can override custom positions while Auto arrange is enabled. Align icons to grid may remain enabled.

Can I restore my original layout?

Yes. Recovery data is prepared before the first Apply operation, and the app provides Restore and startup recovery choices.

What is included free?

Free includes five geometric shapes, Compact text and characters, display and placement controls, Preview, Apply, Restore, manual adjustment, hotkey, and recovery. A one-time durable Premium add-on unlocks decorative shapes, Paired/Bold strokes, SVG, randomization, and JSON layout tools.

Does it work with more than one monitor?

BeautiArt detects connected displays and supports explicit display targeting. Final supported configurations will be listed in the Microsoft Store.
