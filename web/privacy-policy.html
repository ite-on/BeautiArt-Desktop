Privacy Policy

How BeautiArt Desktop processes desktop icon and layout information locally on your Windows device.

Effective date: September 25, 2026

Publisher and scope

BeautiArt Desktop is published by an individual developer using the Microsoft Store publisher display name LA FRET. LA FRET is a publisher name and is not represented as a registered company or separate legal entity.

This policy applies to the BeautiArt Desktop Windows application. Some local folders and technical files may use its original internal name, Beautify.

Privacy contact: etiakuwafon@gmail.com

Summary

  • The application processes desktop icon and display information locally.
  • It does not require an account and contains no advertising or tracking technology.
  • It does not send telemetry, analytics, icon information, layouts, or SVG files to LA FRET.
  • It does not sell personal information and contains no application network client.

Information processed on your device

To preview, apply, save, and restore layouts, the application accesses desktop icon names, Windows Shell identifiers that may contain filenames or local paths, icon positions and spacing, connected-display geometry, application settings, selected SVG paths, and recovery data.

This information is processed locally. LA FRET does not receive it through the application.

Local storage and purpose

Settings and recovery information are stored under %LOCALAPPDATA%\Beautify. User-saved layout files are stored at the location selected by the user.

These files support icon detection, layout previews, user-requested icon movement, restoration, preferences, reusable layouts, and interruption recovery. Layout and recovery JSON may expose icon names, Shell identifiers, local paths, and positions. Review it before sharing.

Sharing, Store processing, and support

The application does not transmit local desktop information. Information leaves the device only when the user independently shares an exported layout, screenshot, diagnostic item, or support message.

Microsoft processes Store acquisition, licensing, updates, ratings, and Store diagnostics under Microsoft's own terms. That processing is separate from the application.

If a user contacts support, LA FRET may receive the email address, message, and attachments voluntarily provided. They are used to investigate and respond, protect the application and users, keep necessary support records, or comply with applicable law. Email and hosting providers process those communications under their own terms.

Retention and deletion

Local files remain until the application replaces them or the user deletes them. Exported files remain in their user-selected locations. Before deleting recovery files, restore the desktop or confirm that the current layout should be kept.

  1. Close BeautiArt Desktop.
  2. Resolve any pending recovery.
  3. Delete %LOCALAPPDATA%\Beautify.
  4. Delete unwanted exported layouts or SVG files from their saved locations.

LA FRET cannot remotely view or delete local files. Contact support to request access to or deletion of support correspondence, subject to applicable legal retention requirements.

Security and children

Local files rely on the security controls of the user's Windows account and device. Keep Windows updated and avoid sharing files containing private names or paths.

BeautiArt Desktop is a general desktop-customization utility and is not directed specifically to children. It does not knowingly collect or transmit children's personal information.

Policy changes and contact

This policy will be updated before adding telemetry, accounts, cloud synchronization, advertising, remote diagnostics, or any feature that changes data handling.

Privacy and support contact: etiakuwafon@gmail.com
