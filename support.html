Support

Safe setup, recovery guidance, and troubleshooting for BeautiArt Desktop.

Support email: etiakuwafon@gmail.com

Before applying a layout

  1. Right-click the Windows desktop, open View, and turn off Auto arrange icons.
  2. Confirm Desktop Status shows the expected icons and displays.
  3. Select Preview before Apply layout.
  4. Keep recovery data until the original arrangement is restored or the current layout is intentionally kept.

Common problems

No desktop icons detected

Confirm Windows Explorer is running, desktop icons are visible, and the app is running in an interactive desktop session. Restart Explorer and then reopen the app.

Icons do not move or return to a grid

Turn off Auto arrange icons. Align icons to grid may remain enabled.

A layout is distorted across displays

Select the intended display and icon scope. Refresh Preview after connecting, disconnecting, rotating, or rescaling a display.

The global hotkey does not work

The default is Ctrl+Alt+B. If another application owns it, use the on-screen Apply and Restore controls.

Recovering a layout

Use the recovery banner or Restore. Recovery files are stored under %LOCALAPPDATA%\Beautify. Do not delete recovery-layout.json or recovery-state.json while a restore is still needed.

Report a problem

Include the app version, Windows version/build, display count and scaling, selected shape and layout options, exact Desktop Status message, reproduction steps, and whether Auto arrange is enabled.

Redact private filenames, paths, account names, and other sensitive information from screenshots or diagnostics. Do not send passwords, payment information, or unreviewed recovery/layout JSON.

Premium purchase and entitlement

  • Install BeautiArt Desktop from Microsoft Store and sign in with the account that owns Premium.
  • Start online once after purchase, then use Unlock Premium again to refresh an already-purchased entitlement.
  • Do not run the app as administrator because Microsoft Store purchase UI is unavailable to elevated applications.
  • Send support the exact license status message, never payment-card information.

Privacy, response, and scope

Read the privacy policy. The application processes layout information locally, so support cannot remotely access or delete files from a user's device.

Support is provided on a best-effort basis. Recovery failures and repeatable data-loss risks are prioritized. Supported Windows versions and architectures are those shown on the Microsoft Store listing.
